# Voice Room Experiment

This folder is the implementation area for the single-voice Gschwätz MVP.

## Local setup

```bash
cp .env.example .env
```

Then edit `.env` and add:

```bash
OPENAI_API_KEY=sk-...
```

The real `.env` is ignored by Git and must never be committed.

See `../../gschwaetz-app-proposal/PARALLEL_BUILD_PLAN.md` for execution objects, ownership and sync points.
