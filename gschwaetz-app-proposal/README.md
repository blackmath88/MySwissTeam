# Gschwätz / Let's Talk

**Meet the argument before the label.**

Gschwätz is a conversational civic-learning prototype for political issues, referenda, and public debates. Instead of presenting party labels first, users meet distinct AI-simulated perspectives as human-scale conversational characters. Only later are the sources, political origins, and institutional positions revealed.

The goal is not persuasion and not attitude change. The goal is to create a safer, more curious space for understanding why reasonable people can disagree.

## Core idea

Traditional flow:

`party label -> expectation -> argument -> reaction`

Gschwätz flow:

`argument -> values -> trade-offs -> reflection -> source / political reveal`

## Product promise

> We don't tell you what to think. We make it easier to keep talking.

## Hackathon MVP

One issue. Three avatars. One conversation flow. One delayed reveal.

1. User chooses a political issue / referendum.
2. User meets 3 unlabeled avatars with distinct positions.
3. User talks by voice or text.
4. Avatars acknowledge trade-offs, uncertainty, and opposing arguments.
5. User reflects on what surprised them.
6. Sources and political origins are revealed.
7. User can inspect evidence and continue with another perspective.

## Core doctrine

1. Understanding before positioning.
2. Argument before identity.
3. Steelman every side.
4. Show uncertainty and trade-offs.
5. Preserve user autonomy.
6. Reward curiosity, not conversion.
7. Reveal evidence and provenance.
8. Never impersonate a real person.
9. Make political simulation explicit.
10. Keep the user in control of the conversation mode.
