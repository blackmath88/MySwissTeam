# Hackathon MVP build plan

## Goal

A polished vertical slice that demonstrates the core interaction:

**unlabeled perspective -> conversation -> reflection -> reveal**

## Scope

Build only:

- 1 political issue
- 3 fictional personas
- text chat
- optional voice input / speech output
- reflection step
- reveal step
- source panel

Do not build:

- user accounts
- personalised political profiles
- recommendation engine
- full CMS
- many topics
- election prediction
- social sharing mechanics

## Milestones

### Milestone 1 — Static experience

- landing page
- issue summary
- 3 avatar cards
- reveal screen

### Milestone 2 — Persona chat

- model integration
- persona prompt
- hidden identity
- 3 suggested question modes

### Milestone 3 — Grounding

- source IDs in persona JSON
- claim citations
- source panel

### Milestone 4 — Reflection

- simple post-chat question
- topic / trade-off summary

### Milestone 5 — Demo polish

- loading / transition states
- avatar voice if time allows
- mobile layout
- short reset button for live demo

## Priority order

1. interaction concept
2. quality of persona content
3. reveal moment
4. source transparency
5. visual polish
6. voice / avatar animation

## Definition of done

A judge can:

1. choose a topic
2. talk to an unlabeled avatar
3. challenge the avatar
4. hear a fair counterargument
5. see uncertainty
6. reveal the source / political background
7. understand the product idea within 3 minutes
