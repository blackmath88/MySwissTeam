# Concept

## Problem

Political information is often encountered through labels before substance: party, ideology, campaign, tribe, media brand. Once identity is visible, the argument is interpreted through an existing social frame.

Gschwätz changes the order.

The user first encounters a coherent perspective, including its values, reasons, uncertainties, and strongest counterargument. Only afterwards does the system reveal which public sources, parties, organisations, institutions, or political traditions contributed to that perspective.

## Product thesis

**Identity should not disappear. It should arrive later.**

The app does not seek artificial neutrality, consensus, or depoliticisation. It preserves disagreement while weakening premature stereotyping.

## What Gschwätz is

- a deliberative conversation interface
- a civic-learning experience
- a perspective simulator grounded in sources
- a low-threshold multilingual interface
- an argument exploration tool

## What Gschwätz is not

- a voting recommendation engine
- a party matcher
- a persuasion system
- a political chatbot pretending to be a politician
- a truth-ranking system for contested value questions
- a debate game with winners and losers

## Success condition

A successful session does not require the user to change their opinion.

A better target is:

> Can the user explain why a reasonable person might disagree with them?

Secondary outcomes:

- user discovers an argument they had not considered
- user identifies a trade-off rather than a slogan
- user becomes less certain about a stereotype, not necessarily about the issue
- user can distinguish factual disagreement from value disagreement
- user can trace claims to sources

## Product doctrine

### 1. Understanding before positioning
Do not ask users to declare a stance before exploring the issue.

### 2. Argument before identity
Delay partisan and organisational labels during initial exploration.

### 3. Steelman every side
Represent positions in their strongest reasonable form.

### 4. Show internal tension
Every perspective should contain uncertainty, costs, counterarguments, and limits.

### 5. Preserve autonomy
Do not tell users what they should believe, support, or vote.

### 6. Reward curiosity
The product celebrates discovery, nuance, and perspective-taking rather than conversion.

### 7. Reveal provenance
Political claims should eventually lead to attributable source material.

## Key conceptual move: argument personas

Do not create "SP bot", "SVP bot", "FDP bot", etc.

Create conversational perspectives such as:

- The Pragmatist — implementation, cost, feasibility
- The Liberal — autonomy, rights, freedom
- The Solidarist — fairness, distribution, inclusion
- The Institutionalist — stability, legitimacy, governance
- The Steward — long-term effects, preservation, sustainability

For each issue, these become issue-specific and can draw from overlapping political sources.

This avoids turning parties into caricatures and lets users discover that arguments do not map perfectly onto party labels.
